# Product Decisions

## Decision 1: React + Vite
The current environment is stable and modern. Vite allows quick iteration and a clean learning path for building a real ecommerce interface.

## Decision 2: JavaScript first
JavaScript is the best start for learning logic, components, and state management before moving deeper into backend and auth systems.

## Decision 3: Build a real storefront first
The first objective is to create a usable e-commerce homepage and catalog experience, not to over-engineer advanced systems before the UI is proven.

## Decision 4: Security by default
Authentication, authorization, validation, and secure handling of data will be considered from the start, even during the MVP stage.

## Decision 5: Learn by building
The project is treated as a real product, with each feature tied to a clear user need and a simple implementation path.
